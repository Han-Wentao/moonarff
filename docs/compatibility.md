# Weka ARFF 格式兼容矩阵

最终目标是完整兼容 Weka ARFF 格式，包括日期格式及其他必要语义。0.2.1 是可复现的阶段版本，尚未达到全部格式兼容。下表的待补齐项属于该目标；数据变换、统计或测试数量不能替代它们。

## 当前可复现范围

| 语义 | 0.2.1 行为 | 验证入口 |
| --- | --- | --- |
| 模式、Numeric / Nominal / String、缺失值 | 读写声明类别域，区分字面量 `?` 与缺失 | 核心测试、LIAC-ARFF 差分、Weka 互操作 |
| 密集／稀疏 | 支持省略的数值／类别／日期默认值；输出显式保留文本和关系 | 稀疏测试及 Weka 双向输出 |
| Date 数值与英文文本 | `yyyy M d D E H h K k a m s S Z X` 的 README 所列宽度；UTC 毫秒 | 日期回归及 Weka epoch 对照 |
| 日期文本解析 | 全称／缩写不依赖输出宽度，大小写不敏感；数字邻接字段正确消费 | `date text widths and adjacent numeric boundaries` |
| 日历与冲突 | Java GregorianCalendar 1582 切换；校验星期、年内日序，拒绝重复字段和混用小时字段 | 日期边界测试、Weka 1582 年内日序样本 |
| Relational | 递归模式、子记录、空关系／缺失关系、内层权重，受共享预算限制 | 关系回归及 Weka 内部嵌套语义对照 |
| 实例权重 | 密集／稀疏行尾权重，默认1；保留有限零、负数和小数 | 权重测试及 Weka 内部权重对照 |
| 增量输入／输出 | 任意 UTF-8 字节边界、逐记录回调和 sink 输出，保留有界当前记录 | 流式错误／边界测试、五个工作流及 Weka 全量／增量对照 |

无时区字段按 UTC 解释，日期输出也规范化到 UTC。英文名使用固定语言环境；Weka 参考进程固定 `en_US` 与 UTC。当前严格拒绝无效日期及有损日期输出，与 Java 默认宽松解析的行为存在差别。

## 必须继续补齐的兼容工作

| 差异或缺口 | 后续实现约束 | 完成判据 |
| --- | --- | --- |
| `yy` 两位年、`G` 纪元、超出当前年份范围 | 显式定义参考日期／两位年窗口及历法，不能依赖运行日期或平台默认值 | 与固定配置 Weka 比较窗口边界、纪元及读写时间戳 |
| `Y w W F u` 周年／周序字段 | 显式定义首周规则、每周起始日和历法切换规则 | 跨年、闰年、1582 切换及字段冲突的双向对照 |
| `z` 时区名和多语言名称 | 设计显式 Locale／时区数据配置，覆盖名称歧义和夏令时；保持运行时无 Java 依赖 | 固定时区数据库版本，比较夏令时空档／重叠、语言名称与偏移 |
| 重复字段、多种小时字段和宽松归一化 | 当前拒绝；后续提供明确配置与可验证的 Java 字段优先级，保留严格模式 | 与 Weka 比较重复字段优先级、溢出日期、缺省字段及错误行为 |
| 稀疏 String／Relational 省略值 | 当前拒绝；需要建模 Weka 字典状态，不能擅自用空值代替 | 覆盖跨记录字典、首次省略、密集／稀疏混合及增量加载 |
| 属性级权重、其他词法及数值兼容差异 | 补齐相应格式模型和可配置语义；当前未知转义、BOM、非有限数值明确报错 | 以 Weka 实际读写样本逐项核对，不以静默忽略实现兼容 |

先扩展日期字段与显式环境配置，再处理字典和其他格式差异；每项工作须同步模式验证、内存与流式接口、密集／稀疏写出、错误语义、文档及独立互操作样本。只有矩阵各项有可复现证据，才可宣称完成相应兼容能力。资源预算和严格输入策略仍需公开，并与格式本身的能力区分。

## 验证与来源

`python scripts/weka_interop.py` 使用校验 SHA-256 的外部 Weka 3.8.6，比较111份合成原始输入、111份Weka写回输入、444份密集／稀疏输出；同时检查内部 epoch、权重、嵌套值和全量／增量一致性。该样本集覆盖表中当前能力，不能证明所有 Weka 文件或全部日期模式兼容。`python scripts/differential.py` 保留 LIAC-ARFF 支持子集的独立对照。参考实现分别安装，不进入生产包。

行为依据为 [Weka ARFF 说明](https://waikato.github.io/weka-wiki/formats_and_processing/arff_stable/) 和 [Java 17 SimpleDateFormat](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/text/SimpleDateFormat.html)。机器学习训练、DataFrame 查询、Java 对象序列化不属于 ARFF 文本格式兼容目标。
